# Changelog

## 0.3.0 — 2026-11-07

- Add explicit, replay-audited baseline/candidate upgrade policies with quality or cost objectives, family floors, resource limits, version eligibility, exact regressions and machine-readable exit codes.
- Publish four reproducible retrospective decision examples, with JSON, Markdown and source/policy fingerprints; retain all v0.2 experiments and scores unchanged.
- Load live workbench summaries and individual trajectories on demand; add deterministic failure diagnosis and paired investigation.
- Support explicitly named, independently budgeted campaigns and read-only ledger reports. Analysis writes separate artifacts instead of changing raw evidence.
- Apply one source-release policy to wheel, sdist and ZIP builds; test synthetic private files, symlinks and stale build outputs. Read package version from project metadata in build and CI.
